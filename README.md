# KR Real Cost - How much does it cost to LIVE in Seoul?

**Problem:** Brazilians dreaming of exchange in Korea only find currency converters on Google. No one shows how much a REAL month costs there - housing, food, transport in BRL.

**Solution:** I built a calculator that simulates monthly living cost in Seoul based on real 2026 average prices (goshiwon, one-room, T-money, 라면, 치킨).

**Features:**
- Live editable exchange rate
- Simulation by days (7 to 90 days)
- Detailed breakdown in Won and BRL
- Money saving tips (꿀팁)

**Tech:** HTML, CSS, pure JavaScript
**Live Link:** https://miguelkrsoul.github.io/seoul-living-cost-calculator/
